# Project: Isha1218 GitHub profile README

## Overview
Creative profile README for github.com/Isha1218: an animated Antarctic hero, Pip (a penguin visitors feed via GitHub issues), and "the iceberg library" shelf of projects.
Live at github.com/Isha1218 (repo Isha1218/Isha1218). Pending: contact links (none known yet).

## Tech Stack
Hand-built SVG (CSS + SMIL animation) generated by Python 3 (stdlib only); GitHub Actions.

## Architecture
- Static art: `scripts/build_art.py` → `assets/hero.svg`, `shelf.svg`, `btn-*.svg`
- Pip: opening an issue titled `pip|fish|krill|book|snowball` triggers `.github/workflows/pip.yml` → `scripts/pip.py` updates `data/pip.json`, redraws `assets/pip.svg`, rewrites README `<!-- PIP:* -->` blocks, replies and closes the issue. 10 snacks/user/day cap.
- `scripts/art.py`: shared penguin drawing + sky.

## Key Files
README.md · scripts/{art,build_art,pip}.py · .github/workflows/pip.yml · data/pip.json

## How to Run
`python3 scripts/build_art.py` (after editing art/projects) · `python3 scripts/pip.py --render` (redraw Pip)
