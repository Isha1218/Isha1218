# Project: Isha1218 GitHub profile README

## Overview
Profile README for github.com/Isha1218 (live). Minimal header (flat penguin catching a fish, name, tag pills, fish counter), a "feed the penguin" button, three dark project cards (BookBro, Aftertaste, Bookflix), tiny link row.
Rejected before: cartoony penguin scene/game, terminal card, resume-style prose.

## Tech Stack
Hand-drawn SVG generated by Python 3 (stdlib); GitHub Actions.

## Architecture
Opening an issue titled "feed the penguin…" runs `.github/workflows/feed.yml` → `scripts/profile.py --feed` bumps `data/fish.json`, redraws the headers, bumps the README cache-buster, replies and closes. 10 fish/user/day.

## Key Files
README.md · scripts/profile.py (TAGS, PROJECTS, art) · .github/workflows/feed.yml · data/fish.json · assets/

## How to Run
`python3 scripts/profile.py` redraws everything; commit and push.
